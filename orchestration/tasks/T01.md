# T01 Spike: ClinicalTrials.gov and version history

Research only; no product code. Write `docs/spikes/ctgov.md` and a runnable probe `scripts/spikes/ctgov_probe.py` (standard library + httpx only). There is no Makefile yet: skip `make check`.

Answer with evidence from real requests:

1. The exact API v2 query for interventional Phase 2, Phase 3 and Phase 2/3 non-small cell lung cancer trials. Total count, and count with overall status COMPLETED or TERMINATED.
2. JSON paths for: eligibility text, min/max age, enrollment count and type (ESTIMATED vs ACTUAL), overall status, why stopped, start date, primary completion date, phases, arms and interventions, locations, sponsor class, first-posted date.
3. Version history: how to fetch (a) the list of versions with dates and (b) the full record at a version. 4. Five demo-trial candidates: NSCLC, Phase 2 or 3, started 2018 or later, TERMINATED with an accrual-related why-stopped, whose eligibility text changed after the start date. For each: NCT ID, title, start date, why stopped, what changed in eligibility and when.
5. Gotchas: pagination, missing fields, rate limits, date formats.
