# T12 Criteria parser, visit estimator, rule diff, embeddings

Owns `clinova/parse/` and tables `criteria_rules`, `trial_embeddings`. Read ARCHITECTURE.md 5.2 and 6, `docs/CONTRACTS.md` and the fixtures.

Fan out three parallel parts:

1. **Parser.** `parse_protocol(eligibility_text, schedule_text=None, *, trial_id, version_no) -> ParsedProtocol` via `common.llm.generate_json`. One rule per atomic condition, mapped to ClinicalField; normalized units (CrCl mL/min; liver labs as ×ULN; counts with stated units). Unmappable → `field=other`, `parse_status=unparseable`: flag, never guess. Infer setting (first_line / second_line_plus). After the model returns, deterministic sanity checks (plausible range per field, operator valid for type) flag violations. Export the JSON schema to `parse/schema.json`.
2. **Visits.** Extract visits from schedule text when given. `estimate_visits(trial_record)` builds a schedule from design fields (cycle length, route, arms, imaging cadence typical for the phase) with `estimated=True`.
3. **Gold set and diff.** `tests/parse/gold/` with 12 real NSCLC eligibility texts (from the database, or fetched directly from the API if T11's data isn't there yet), annotated by you reading the text, not by Gemini. An evaluator reports field-level precision and recall. `parse.diff.diff_rules(old, new)` returns per-field changes (relaxed, tightened, removed, added).

Then `parse/embed.py`: `embed_trials(nct_ids)` with `common.llm.embed` at 768 dims into `trial_embeddings`; `nearest(vector_or_nct, k)` by pgvector cosine distance.

Batch CLI, resumable, run as background jobs: `python -m clinova.parse run --versions first` (every trial's first version, test split first) and `--versions amended` (post-change eligibility for trials with `label_amend`), plus `python -m clinova.parse embed`. Until T11's rows appear, develop on fixtures and the gold set; poll the `trials` table every few minutes and start the batches when rows exist.

**Done when:** gold-set precision and recall are reported in the handoff, the batches are running against real trials, and `make check` passes.
