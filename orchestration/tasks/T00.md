# T00 Bootstrap, frozen contracts, merge spikes

You are the integrator. Build the skeleton and the frozen contracts that ~20 parallel agents on two laptops and two model families will build against, so they never collide. Do NOT implement components. Read `docs/ARCHITECTURE.md` end to end first, then plan, then build.

Already in the repo, do not overwrite: `AGENTS.md`, `CLAUDE.md`, `docs/ARCHITECTURE.md`, `orchestration/`, `scripts/orch.sh`, `.claude/`, `.codex/`, `.env.example`. You may append to `.gitignore`.

Build, fanning out to parallel subagents where parts are independent (for example: one for schema + db, one for contracts + fixtures, one for packaging + CI):

1. **Package.** Python 3.11 package `clinova/` with uv (`pyproject.toml`), subpackages ingest, parse, cohort, simulate, model, optimize, loop, api, app, common. Also `db/`, `tests/` (one subfolder per module plus `tests/fixtures/`, shared `conftest.py`), `docs/handoff/`, `docs/contract_changes/`, `docs/reviews/`, `docs/spikes/`, `docs/figures/` (with .gitkeep). Dependencies: httpx, tenacity, pydantic v2, pydantic-settings, python-dotenv, google-genai, psycopg[binary,pool], pgvector, pandas, pyarrow, numpy, lightgbm, scikit-learn, shap, optuna, fastapi, uvicorn, streamlit, plotly, pyyaml, matplotlib; dev: pytest, pytest-asyncio, hypothesis, ruff, respx, playwright.

2. **`clinova/common/config.py`.** pydantic-settings reading `.env` from the working tree root and, failing that, from the main clone root (`git rev-parse --git-common-dir`/..). Settings: CLINOVA_MODE (demo|live), GEMINI_API_KEY, GEMINI_MODEL_FAST, GEMINI_EMBED_MODEL, EMBED_DIM=768, GEMINI_CONCURRENCY=8, MAX_GEMINI_CALLS=12000, DATABASE_URL, DATA_DIR (default: main clone `.data/`), SEED=42, DEMO_NCT_ID (optional), amendment cost constants (Phase II $141,000; Phase III $535,000; about 3 months delay; source Regeneron Starter Sheet 01). Look up Google's current Gemini API docs for the right model ids and `google-genai` usage before choosing defaults; model ids appear nowhere else in the code.

3. **`clinova/common/llm.py`, the only Gemini entry point.** `generate_json(prompt, schema, *, namespace, seed, temperature=0.2)` and `embed(texts, *, namespace, dim=EMBED_DIM)`, sync and async. Structured JSON output via the SDK's response schema, validated with pydantic, one repair retry. Cache in Postgres `llm_cache` (key = sha256 of namespace+model+prompt+schema+seed). Demo mode is cache-only: a miss raises `CacheMiss`, no network. Live mode: asyncio semaphore at GEMINI_CONCURRENCY, exponential backoff with jitter on 429/5xx, usage rows in `llm_usage` tagged with a fingerprint of the API key (last 6 chars hashed), and a hard stop (`BudgetExceeded`) when that fingerprint's call count reaches MAX_GEMINI_CALLS.

4. **`clinova/common/db.py`.** Connection pool, `get_conn()`, `apply_schema()` (idempotent).

5. **`db/schema.sql`.** Every table in ARCHITECTURE.md section 6. Extensions timescaledb and vector. Hypertable primary keys include the time column. `trial_embeddings.embedding vector(768)` with an HNSW cosine index. Continuous aggregate over `prediction_scores` by month (verify against TimescaleDB docs). Idempotent: safe to run twice. Apply it to Tiger Cloud (`DATABASE_URL`) and confirm every table exists.

6. **`clinova/contracts.py`.** Pydantic models every task imports, with generous Field descriptions (they are the spec): TrialRecord; VersionEvent; ClinicalField enum (age, sex, ecog, stage, histology, egfr_status, alk_status, ros1_status, pdl1_tps, brain_mets [none|treated_stable|untreated], leptomeningeal, prior_lines, prior_platinum, prior_immunotherapy, crcl_ml_min, anc, platelets, hemoglobin, ast_x_uln, alt_x_uln, bilirubin_x_uln, life_expectancy_months, measurable_disease, autoimmune_disease, interstitial_lung_disease, active_infection, cardiac_condition, pregnancy, consent_capacity, other); Operator (lt, le, gt, ge, eq, ne, in, not_in, present, absent); CriteriaRule (rule_id, kind inclusion|exclusion, field, operator, value, unit, raw_text, parse_status ok|unparseable, locked); Visit (visit_no, name, day, procedures, est_hours, requires_travel, invasive, remote_ok, estimated); ParsedProtocol (trial_id, version_no, phase, setting first_line|second_line_plus|any, rules, visits, unparseable); ClinicalTraits; Persona (persona_id, age, sex, race_ethnicity, life-context fields, clinical); ScreenResult; Funnel (sequential stages + per-rule marginal exclusions); AgentDecision (persona_id, enroll, dropout_visit, reason, burden_tags); SimRunSummary; RiskScore (target accrual_fail|shortfall|amend, p, ci_low, ci_high, confidence high|medium|low, top_drivers); CriterionFlag (rule_id, where, why, what_to_do, delta_p); Edit (kind relax_rule|drop_rule|cut_visit|merge_visits|make_remote, target_id, new_value); Fix (fix_id, edits, delta_enroll, delta_dropout, delta_diversity, ranges, dollar_value, precedents); Prediction; Feedback; RunStatus.

7. **Stubs** with final signatures, docstrings and `raise NotImplementedError`: ingest.pipeline.run; parse.parser.parse_protocol; parse.visits.estimate_visits; parse.diff.diff_rules; parse.embed.embed_trials / nearest; cohort.generate.generate_cohort; simulate.screen.screen / apply_edits; simulate.diversity.diversity_index; simulate.agents.run_agents; simulate.runner.simulate_trial; simulate.surrogate.Surrogate; model.features.build_features; model.train.train; model.predict.score / flag_criteria; optimize.search.optimize; loop.ledger.record_prediction / record_feedback; loop.checker.check_outcomes; loop.replay.run_replay. Each subpackage gets a `__main__.py` CLI stub.

8. **Fixtures** in `tests/fixtures/`, hand-written and realistic: a synthetic second-line NSCLC eligibility text and visit schedule; its ParsedProtocol (about 15 rules, 8 visits); 200 Personas; a Funnel; 25 AgentDecisions; a SimRunSummary; RiskScores; CriterionFlags; three Fixes; validation metrics JSON and replay JSON in the final shapes. `tests/test_contracts.py` round-trips each one.
