# T23 Protocol optimizer

Owns `clinova/optimize/` and table `fixes`. Read ARCHITECTURE.md 5.8 and the example query in section 6, `docs/CONTRACTS.md`. **Goal:** three trade-off fixes per protocol, with ranges, a dollar value and precedents, in under 10 seconds.

Define a `Scorer` protocol (eligible_frac, enroll_rate, dropout_risk, p_shortfall, p_amend for a rule set and visit list). Build against a stub; switch to `model.predict` (T22, on origin/task/T22-model) and `simulate.surrogate.Surrogate` (merged at Gate 1, refit by T24) when available, and note the swap for Gate 2.

Fan out parallel parts:

1. **Edit space** `optimize/edits.py`: relax ladders from thresholds other NSCLC trials actually used, read from `criteria_rules` (for example CrCl 60→50→45→30; ECOG ≤1→≤2; untreated brain mets excluded → treated-and-stable allowed); drop rule; cut visit; merge adjacent visits; make a visit remote where procedures allow. Locked rules never change (pregnancy and consent_capacity locked by default).
2. **Search** `optimize/search.py`: Optuna NSGA-II, at most 3 edits per candidate. Objectives: enrollment speed (eligible_frac × surrogate enroll_rate, adjusted by p_shortfall), dropout risk (surrogate), diversity (`simulate.diversity`). Each evaluation re-screens a cached cohort. Return the Pareto front, deduplicated, and three picks: fastest enrollment, lowest dropout, best balance.
3. **Ranges and money.** Re-evaluate picks across 5 cohort seeds and the bootstrap models. Dollar value = drop in p_amend × the phase's median amendment cost from config, labelled expected value.
4. **Precedents** `optimize/precedents.py`: comparable NSCLC trials (pgvector nearest) that used the looser threshold and completed; and the example query: among comparable trials with the original threshold, the share that later widened it and median months after start (from `trial_versions`).

Save to `fixes`. CLI `python -m clinova.optimize --trial <NCT>` (default: the selected demo trial). Tests and a speed benchmark.

**Done when:** the demo trial gets three fixes with ranges, dollars and precedents in under 10 s, and `make check` passes.
