# G1 Gate 1

You are the integrator, working on `main` in the main clone (no task branch; `scripts/orch.sh start` is not used). Follow "Integrator rules" in PROTOCOL.md. Read every `docs/handoff/T1*.md` and `docs/contract_changes/*`.

1. **Merge** in order: T11, T12, T13, T14, T15, then T16 if it is `done` with `ok:`. Apply contract changes; re-run `make db-apply` if the schema changed.
2. **Swap fixtures for real modules** wherever both sides exist: runner uses the real cohort and screen; API and app call real parse, screen and simulate.
3. **Cross-model label check.** Spawn a `clinova-reviewer` subagent (Claude) to classify the 40 stop reasons in `docs/labels_spotcheck.csv` blind (it sees only the raw text and the class list), then compute agreement with the Codex-built labels. If agreement is below 85%, fix the classification prompt in `clinova/ingest/`, re-run classification for all trials (cached calls are free), and re-check. Record agreement in the gate report.
4. **Pick the demo trial.** If `DEMO_NCT_ID` is set in `.env`, use it. Otherwise, from `docs/demo_trial.md` candidates, choose by this rule: test split; terminated for accrual; eligibility widened before termination; the widened criterion maps to a ClinicalField other than `other`; most parseable rules; ties → earliest termination. Write "Selected: NCT…" and the reason at the top of `docs/demo_trial.md`, and set the default `DEMO_NCT_ID` in `clinova/common/config.py`. Pick two backups the same way.
5. **End-to-end run.** `scripts/e2e_demo.py`: load the demo trial's first registered version, parse, 1,000 personas for its setting, screen, agents live with 2 seeds, store the run. Run it.
6. **Report** `docs/gate1_report.md`: funnel numbers and the top exclusion; eligible fraction vs the published sanity range; enroll rate and dropout curve; whether the criterion the sponsor later widened is among the top 3 exclusions (honest either way); data counts (trials, labeled, parsed, embedded) and background job progress; label agreement; anything that looks wrong with a suspected cause.
7. **Review.** Spawn a `clinova-reviewer` subagent on the merged main: leakage, ownership violations, untested logic, silent fixture fallbacks on live paths. Fix cheap issues; list the rest.
8. **Publish.** `make check` green. `git push origin main`, then `scripts/orch.sh done G1 ok "<summary>"`, then `scripts/orch.sh gate 1 "<summary>"`, where the summary reads like `<n> trials / <n> labeled; demo <NCT>; top exclusion <field>; label agreement <pct>`. Notify `A-claude ✓ Gate 1` with the same summary.
