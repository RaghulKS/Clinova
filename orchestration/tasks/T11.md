# T11 Data ingestion and labels

Owns `clinova/ingest/` and tables `trials`, `trial_versions`, `outcomes` (outcomes rows written here are initial labels; T21 owns updates later). Read ARCHITECTURE.md sections 5.1, 6, 7 and `docs/spikes/ctgov.md`.

**Goal:** about 1,500 Phase 2/3 interventional NSCLC trials in Tiger Cloud with first-version fields, version events, three labels and a split.

1. Build first, alone: `ingest/ctgov.py`, an httpx client with retries, polite rate limiting and a raw-response disk cache under `DATA_DIR/raw`.
2. Then fan out three parallel parts:
   - **Pull:** the spike's search query; fetch each current record; map to TrialRecord.
   - **History:** each trial's version list and first registered version; diff consecutive versions on eligibility text, enrollment count and type, primary completion date, overall status, location count; write VersionEvents. If history access fails, use the spike's fallback and say so.
   - **Labels:** (a) `stop_category` via `common.llm.generate_json` with a pydantic schema (accrual, safety, efficacy_futility, business_funding, other, unknown); `label_accrual_fail` = TERMINATED and accrual. (b) `label_shortfall` = actual < 0.8 × first-version anticipated enrollment, for ended trials with an ACTUAL count. (c) `label_amend` = eligibility changed after start date and Gemini classifies the old-vs-new change as widened or mixed (else narrowed or administrative).
3. `ingest/load.py` writes to the database. Split: train if start < 2018-01-01, test if on or after, `pending` if not ended (no labels). Store first-version fields separately from current fields and never overwrite them.
4. CLI `python -m clinova.ingest run [--limit N]`, resumable. Run the full pull as a background job (AGENTS.md) and keep working while it runs.
5. Outputs: `docs/labels_spotcheck.csv` (40 random stop-reason classifications with the raw text, for Gate 1's cross-model check); `docs/data_report.md` (counts by status, split and label; prevalence; history coverage; oddities); `docs/demo_trial.md` (top 5 test-split candidates: terminated for accrual, eligibility widened before termination, rich eligibility text; for each the NCT ID, the widened criterion in plain words, dates, and a score).
6. Tests with recorded responses (respx), no network.

**Done when:** the background pull is running or finished, at least 200 trials are loaded with labels, all outputs above exist, and `make check` passes. Then finish per the contract.
