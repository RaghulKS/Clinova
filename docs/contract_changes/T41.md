# T41 integration notes for G4

No shared code changes proposed. Merge T41's owned README.md and scripts/check_numbers.py.

After merging T42 and T43, run `uv run python scripts/check_numbers.py` from the repository root. Default mode requires all four artifacts: README.md, docs/deck/outline.md, docs/video/script.md, docs/submission/devpost.md. Do not use --allow-missing at the ship gate.

The checker reads the committed docs/metrics.json and docs/replay.json. It associates target table cells with their model/baseline/count/interval columns, permits only displayed rounding (including percentages), and rejects numeric claims for unavailable targets. Narrative claims with ambiguous sources need an ordered Markdown comment after the claim, for example:

```markdown
Train/test: 1,424 / 360. <!-- numbers: metrics.n_train metrics.n_test -->
Replay Brier 0.078241 updated vs 0.076678 frozen. <!-- numbers: replay.summary.retrained_brier replay.summary.frozen_brier -->
```

Source paths: `metrics.targets.accrual_fail.auc.value`, `.auc.ci_low`, `.auc.ci_high`, `.baseline_auc.*`, `.brier`, `.baseline_brier`, `.n_test`, `.n_pos` (likewise shortfall); `metrics.n_train`, `metrics.n_test`; `replay.n_months`; `replay.summary.retrained_brier`, `.frozen_brier`, `.n_scored`, `.n_unique`, `.n_train`; monthly `replay.months.2020-01.retrained.brier` or `.frozen.brier`. The replay summary fields are parsed from the source JSON's summary, not manually entered constants.

Do not annotate a baseline claim with a model path: recognized semantic conflicts fail. Do not treat metric-detail-only paired differences, demo metrics, timings, source dates or hardware numbers as fields in metrics.json/replay.json. Quantitative claims outside these sources need their own evidence and manual review; the checker is not a scientific auditor. Demo lines linking docs/demo_results are excluded from this two-source check.

Run `uv run python scripts/check_numbers.py --self-test` for the stdlib-only regression checks. At T41, `--allow-missing` is used only because the other three owned presentation files are not merged yet. Default mode must fail when they are absent.
