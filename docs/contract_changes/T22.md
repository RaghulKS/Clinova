## 1. T11 `clinova/ingest/pull.py`: split trials that have a month-only start date (high impact)

**Why.** `map_trial` only sets the train/test split when `startDateStruct.date` is an exact `YYYY-MM-DD`. CT.gov often gives `YYYY-MM`, e.g. `2016-06`. Those ended trials stay `pending` and get no labels. At hour 5.0 this applied to **276** of the loaded trials: every pending row had a null `start_date`, and the sampled ones had dates like `2016-06`, `2007-02` and `2012-04`. That is more trials than the labeled train split (146 accrual labels). A month is enough to place a trial on either side of 2018-01-01: `2017-12` is train and `2018-01` is test, so the split rule itself does not change.

```diff
@@ def map_trial(current: dict, first: dict | None = None, *, first_version_date: str | date | None = None,
-    start = _exact_date(status_module.get("startDateStruct", {}).get("date"))
+    raw_start = status_module.get("startDateStruct", {}).get("date")
+    start = _exact_date(raw_start)
+    if start is None and isinstance(raw_start, str) and re.fullmatch(r"\d{4}-\d{2}", raw_start):
+        start = date.fromisoformat(f"{raw_start}-01")  # month precision is enough for the 2018-01-01 split
```

After this, re-run the label step for the affected trials (`split` and `label_*`), using the same code path as for any newly ended trial. T22 needs no change: `python -m clinova.model train && python -m clinova.model evaluate` picks them up. The background `watch` job also retrains on its own once labeled train trials grow by 20%.

## 2. Integrator `clinova/common/config.py`: make the model bundle directory configurable

**Why.** Bundles are saved to `MAIN_ROOT / "models"` (gitignored), so every worktree and the main clone see the same latest bundle. Once a bundle exists there, `tests/api/test_routes.py` runs the real model instead of the fixtures. The tests pass either way: `score` always returns three RiskScores, and with no bundle it raises `NotImplementedError`, so the API falls back to its fixtures. But the result depends on the environment. A setting would let `tests/conftest.py` (T33) point the tests at an empty directory, and let Docker (T31) point at a seeded one.

```diff
@@ class Settings(BaseSettings):
     DATA_DIR: Path = MAIN_ROOT / ".data"
+    MODELS_DIR: Path = MAIN_ROOT / "models"  # T22 model bundles (models/<version>/bundle.joblib)
```

and in `clinova/model/train.py` (T22 will apply this once the setting exists):

```diff
-MODELS_DIR = MAIN_ROOT / "models"  # shared by every worktree; gitignored
+MODELS_DIR = get_settings().MODELS_DIR
```
