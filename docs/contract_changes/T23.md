## Pending: paired bootstrap risk samples from T22

`clinova.model.predict.score` is the frozen point-scoring API and is already used
by `clinova.optimize.scoring.ModelScorer`. The optimizer supplies the edited
`ParsedProtocol` and an ephemeral `SimRunSummary` from the fitted behavior
surrogate. It never calls Gemini and never writes to simulation/model tables.

The existing `RiskScore.ci_low/ci_high` cannot establish uncertainty in a change:
subtracting marginal endpoints discards the before/after correlation. Please add
this exact API to `clinova/model/predict.py` and document it in `docs/CONTRACTS.md`:

```python
def score_samples(
    protocol_or_trial: ParsedProtocol | str,
    *,
    sim: Sequence[SimRunSummary] | None = None,
    model_version: str | None = None,
) -> list[tuple[float, float]]:
    """Return calibrated (p_shortfall, p_amend) for each fitted bootstrap model.

    For one immutable model bundle, index i identifies the same bootstrap model
    across all original/edited protocols and cohort seeds. Order and count must
    remain stable. Use edited protocol rules/visits and the supplied simulation
    summary when rebuilding features; never substitute cached original features.
    Return [] when the bundle has no fitted bootstrap models. A missing model
    artifact may raise FileNotFoundError. Never synthesize draws from CI endpoints.
    """
```

T23's local adapter detects `predict.score_samples` automatically on construction.
Gate 2 needs no optimizer redesign: merge T22 and publish its frozen score API,
bootstrap hook and model artifacts, then rerun `python -m clinova.optimize
--benchmark`. A caller can inject `ModelScorer(bootstrap_fn=...)` before the hook
is merged. Tests verify paired differences, mismatched before/after counts, stable
counts across seeds, and explicit absence of fitted draws.

The paired 2.5/97.5 percentile range of `after.p_amend - before.p_amend` is evaluated
across five cohort seeds and the same model draws. Enrollment/dropout/diversity
range variation comes from the five cohorts and behavior surrogate. Risk bootstrap
draws do not establish behavior-surrogate uncertainty. Enrollment deltas retain
the frozen `eligible_frac * enroll_rate` definition; the search objective also
adjusts speed by `1 - p_shortfall`.
