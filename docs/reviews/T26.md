### Major 2 — held-out protocols influence the criterion edit policy

`clinova/model/features.py:463` passes all loaded train and test protocols into `fit_ref`; `:350–359` uses their numeric values to build frozen relax ladders. `clinova/model/predict.py:203–207,235` uses those ladders to select candidate edits, which then influence flags and the future held-out hit rate. `docs/handoff/T22.md:101` explicitly discloses this choice.

**Fix:** pass only training-ID protocols to `fit_ref` for ladder construction, or use a separately frozen external rule vocabulary. Preserve the allowed train-only medians/PCA logic. Regenerate flags and future hit-rate results using that frozen policy.

### Aggregate recomputation and independent bootstrap helper check

```sh
.venv/bin/python - <<'PY'
import json
import numpy as np
from sklearn.metrics import brier_score_loss
from clinova.model.evaluate import auc_ci, paired_diff_ci
m=json.load(open('docs/metrics.json'))
train={'accrual_fail':(146,21),'shortfall':(129,61)}
for x in m['targets']:
    n,pos=train[x['target']]
    q=pos/n
    bins=x['reliability']
    mean_p=sum((b['mean_pred'] or 0)*b['n'] for b in bins)/x['n_test']
    const=(x['n_pos']*(1-q)**2+(x['n_test']-x['n_pos'])*q*q)/x['n_test']
    print(x['target'], 'bin_n',sum(b['n'] for b in bins),'bin_pos',sum((b['frac_pos'] or 0)*b['n'] for b in bins),'train_prev',q,'test_prev',x['n_pos']/x['n_test'],'mean_p',mean_p,'constant_brier',const)
y=np.array([0,0,1,0,1,1,0,1])
p=np.array([.1,.6,.8,.4,.3,.7,.5,.2])
pb=np.array([.2,.1,.7,.3,.6,.4,.5,.8])
def independent_auc(labels,scores):
    pos=scores[labels==1][:,None]
    neg=scores[labels==0][None,:]
    return float(((pos>neg)+.5*(pos==neg)).mean())
rng=np.random.default_rng(0)
a,diffs=[],[]
for _ in range(1000):
    ix=rng.integers(0,len(y),len(y))
    yy=y[ix]
    if 0<yy.sum()<len(yy):
        aa=independent_auc(yy,p[ix])
        a.append(aa)
        diffs.append(aa-independent_auc(yy,pb[ix]))
actual,paired=auc_ci(y,p),paired_diff_ci(y,p,pb)
print('AUC_helper',actual.model_dump(),'reference',independent_auc(y,p),np.percentile(a,[2.5,97.5]).tolist())
print('paired_helper',paired.model_dump(),'reference',independent_auc(y,p)-independent_auc(y,pb),np.percentile(diffs,[2.5,97.5]).tolist())
print('bootstrap_valid_draws',len(a),'Brier_sklearn',brier_score_loss(y,p),'Brier_numpy',np.square(y-p).mean())
assert np.allclose([actual.value,actual.ci_low,actual.ci_high],[independent_auc(y,p),*np.percentile(a,[2.5,97.5])])
assert np.allclose([paired.value,paired.ci_low,paired.ci_high],[independent_auc(y,p)-independent_auc(y,pb),*np.percentile(diffs,[2.5,97.5])])
PY
```
