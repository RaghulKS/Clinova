# T13 handoff

## What works

- `cohort.generate` provides validated Persona objects and an exact 42-column dataframe; deterministic for fixed source snapshot, n, seed and setting. No implicit network calls.
- Licensed NVIDIA Nemotron-Personas-USA source download, attribution, snapshot metadata, SHA-256 verification, resumable block cache, and age×sex importance resampling to the sourced NSCLC margins. The source must cover every positive-mass target cell; unavailable, corrupt, unlicensed or unsupported data uses the explicit deterministic fallback.
- Clinical state sampled conditionally from the preserved spike YAML: age-dependent ECOG, smoking/race-dependent exclusive EGFR/ALK/ROS1, age/histology brain-metastasis risk, line-of-therapy history, exact Cockcroft–Gault and correlated lab abnormality priors.
- Vectorized screening implements all contract operators, missing-value pass semantics, skipped rules, exact sequential and marginal/only-rule exclusions, per-persona details, and immutable rule edits with locked/unknown target protection.
- Diversity is one minus mean total-variation distance across NSCLC age, sex and exclusive race/ethnicity marginals. Exact reference marginals score 1.0; empty cohorts score 0.0. Unknown demographic mass counts as unmatched.
- Golden fixture exactly reproduces the existing full Funnel JSON, 56/200 eligible (28%); this is a synthetic fixture, never clinical validation.

## How to run

```bash
uv sync
uv run python scripts/get_personas.py --n 20000 --seed 42 --workers 1
uv run python -m clinova.cohort generate --n 10000 --seed 42 --setting second_line_plus --out /tmp/cohort.parquet
uv run python -m clinova.cohort.sanity --out docs/cohort_sanity.md
make check
```

Settings are loaded exclusively via `get_settings()`. Persona records are under `DATA_DIR/personas/` (normally the main clone's ignored `.data/personas/`); no downloaded records or secrets are committed. `clinova/cohort/PERSONAS_ATTRIBUTION.md` and the accompanying metadata retain CC BY attribution and modifications. The downloader accepts `--data-dir` for isolated runs and tests.

## What is assumed or limited

There are no LLM calls and no real patient data in this task. Published clinical distributions and all 43 original `source:` entries remain unchanged; tests assert the entire original YAML is preserved. Unsupported implementation priors are marked `assumption: true` with empty sources or sources documenting direction only. Social priors are consumed from `personas_assumptions.yaml`.

The fallback is census-inspired social priors with NSCLC age/sex margins, not a calibrated ACS population. Geography is preserved as narrative context, but travel/access distances are sampled independently because no ZIP–RUCA or cancer-center lookup is available. Caregiving, income, risk tolerance, literacy and race are imputed, not source observations. No text or geography infers ancestry.

The clinical nonsquamous group is represented as adenocarcinoma; subtype-specific screens are approximate. Stage subgroups, prior platinum/immunotherapy shares, laboratory values conditional on failure, frailty magnitude, life expectancy and additional comorbidities are assumptions. ALK/ROS1 younger-age effect size is also assumed. AST and ALT share the same sampled abnormality/value. PD-L1 is sampled for driver-positive patients from an explicitly modified prior because the frozen contract requires numeric TPS and cannot represent missing test status. No distribution was tuned to outcome labels or published eligibility percentages.

## Decisions

- Keep the frozen public interfaces and contracts intact; no shared-file changes requested.
- Sample uniform random non-overlapping 100-row blocks using Hugging Face's rows API instead of introducing `datasets` or downloading multi-GB shards. This is block sampling, not IID individual-row sampling. Record source revision and reject a revision/license change during acquisition.
- Importance resampling uses age×sex product targets because only demographic marginals are available; preserve within-cell persona context and sample race separately.
- Use exclusive Hispanic coding and scale non-Hispanic race probabilities by 0.94 to fit the contract. Source ethnicity overlap is unavailable in the resulting Persona.
- Missing screen columns or malformed rules marked parseable raise errors; missing individual values pass. Unknown ordinal values raise rather than silently impose an arbitrary rank. Unparseable rules are listed and skipped.
- Visit edits are ignored by `apply_edits` and remain optimizer responsibility. Empty screen eligible fraction is zero.
- Report a low fixture eligibility share honestly, including its weakly supported prior immunotherapy restriction. Do not calibrate the simulator to the literature's different denominators.

## Open issues

Clinical and social prior uncertainty remains substantial. Eligibility fractions are plausibility checks on virtual patients and do not establish clinical validity. Replace priors with measured population tables when available. The schema's lack of biomarker-test missingness and overlapping ethnicity limits representation; no shared contract modifications are necessary to consume this implementation.
