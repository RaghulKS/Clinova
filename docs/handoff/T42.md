# T42 handoff: 12-slide deck

Status: see the `done/T42` tag message. Owns `docs/deck/`.

## What works
- `docs/deck/build_deck.py` builds everything in one run: `clinova.pptx` (16:9, 12 slides, speaker notes on every slide), `outline.md`, the charts in `img/`, and with `--render` also `clinova.pdf` (LibreOffice headless) and `render/slide-01.png` to `slide-12.png` (PyMuPDF).
- No number is typed by hand. The script reads every value at build time from:
  - `docs/metrics.json` and `docs/metrics_detail.json`: AUC, CIs, paired AUC gains, Brier, base-rate Brier, n;
  - `docs/replay.json`: pooled Brier for both arms, weighted by `n_scored`, which reproduces G2's 0.0782 vs 0.0767;
  - `docs/demo_results/NCT03232892.json` and `_optimize.json`: demo flags, risk, percentile, the three fixes;
  - `docs/demo_trial.md`: the demo NCT, stop reason and termination date;
  - the cited table in `docs/ARCHITECTURE.md` section 2: problem figures;
  - `orchestration/tasks/*.md`: task count;
  - `git remote`: repo URL.
- Missing sources:
  - A missing value renders as `[TBD: ...]` and stamps the slide "DRAFT".
  - `--final` exits non-zero if any placeholder is left.
  - Charts drawn from fixtures carry an "ILLUSTRATIVE FIXTURE" watermark and only appear with `--fixture-charts`.
- Slide titles and lines follow the data:
  - Validation says "not yet shown to beat a simple baseline" when the paired CI includes zero.
  - Replay says "did not beat the frozen model" when retrained Brier ≥ frozen.
  - The backtest title says whether the sponsor-removed rule is in the top 3 flags.
  - The optimizer hides dollars when every fix has $0 (placeholder amendment model).
- New charts, all large type:
  - `img/auc_vs_baseline.png`: AUC vs baseline with CI whiskers; shortfall is tagged "not validated".
  - `img/auc_gain.png`: paired AUC gain vs the logistic baseline and vs sponsor type alone. It stands in for the hit-rate chart, which is not computable.
  - `img/hit_rate.png`: drawn only when `metrics.json` has a hit rate.
  - `img/replay_brier.png`, `img/demo_flags.png`, `img/reliability.png` (unused while the gain chart exists).
- The script reports approximate text fit (Arial metrics) and checks that speaker notes are 60–90 words. Every rendered slide was viewed.

## How to run
```bash
uv run --with python-pptx --with pymupdf python docs/deck/build_deck.py --render --final
```
LibreOffice: no Homebrew on this laptop. It was installed by downloading the 26.2.6 aarch64 dmg and copying `LibreOffice.app` to `~/Applications`. The script finds `~/Applications/LibreOffice.app/Contents/MacOS/soffice`.

## Decisions
- **The builder lives in `docs/deck/`**, which T42 owns, not in `scripts/`, which the task file does not name. It runs with `uv run --with python-pptx --with pymupdf`, so `pyproject.toml` (integrator-owned) is untouched.
- **G2 changed what can be claimed** (`docs/gate2_report.md`, "Cuts recommended"). The deck follows it:
  - no hit rate, simulation benefit, amendment risk or dollars;
  - the demo trial is shown as an accrual miss (p at the 50th test percentile);
  - flags are presented as an exclusion-share ranking.
- **The backtest slide uses G2's cached flags** (`docs/demo_results`), not the Gate 1 funnel. The two use different cohorts (unconditional vs second-line setting applied), and mixing them would confuse.
- **Problem-slide figures** are parsed from the cited table in ARCHITECTURE.md section 2 (Starter Sheet 01, PMC10028157). They are not model outputs.
