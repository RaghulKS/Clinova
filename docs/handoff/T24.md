## What works

- Deterministic SHA-256 rank with seed 42, round-robin strata across split and all three label values (True, False, missing). Mandatory demo/backups and every observed test amendment-positive override the requested sample size. Labels only select samples; they never enter protocol offers, view features or surrogate input matrices.
- Initial selection was 400 trials (67 train, 126 test, 207 pending). After persistent daily quota exhaustion, `data/sim_sample.csv` was regenerated for the task's 250-trial/one-seed fallback: 101 train, 111 test, 38 pending. All three demo IDs remain. No amendment-positive labels were observed at selection; missing labels are not verified negatives. Concurrent ingestion can change these counts. Every 25 trials and at retry-pass boundaries, newly observed mandatory test amendment positives are appended without removing frozen selections.
- Batch executes one trial and one seed at a time, persists completed seeds immediately, and skips existing trial/version/model/seed combinations. Demo/backups request seeds 1 through 5. Generic failures receive one final retry pass; final provider 429 or budget exhaustion pauses the whole live batch. All LLM work remains through common.llm.
- Budget ceiling is the minimum of initial usage plus `--max-calls` and initial usage plus 85% of the remaining shared allowance minus GEMINI_CONCURRENCY. Common.llm checks the total shared usage before each request and retry. Other tasks' usage counts toward the same ceiling; its existing in-flight overshoot caveat remains. The original nominal plan was 6,872 requests including extra demo seeds, not the retry upper bound. The CLI now includes demo extra seeds and requested agent count in dry-run estimates.
- `sim_features` has one row per registered trial (`nct_id`), latest current-model first-version run per seed, excluding fixture and amended versions. Columns: eligible_frac, enroll_rate, dropout_visit_2, dropout_visit_4, dropout_last, dropout_area, reason_* for every BurdenTag, seed_spread, n_seeds. Dropout area is trapezoidal area on visit index, normalized by visit count, starting at zero before visit 1. Burden shares come from all observed adverse persona outcomes, avoiding truncation of the summary's top-five list. Reasons can overlap. Seed spread is population SD of enrollment rates.
- No-agent enrollment/reason features and no-enrollee dropout features are NULL, not synthetic zeros. A live SQL assertion verified this for NCT04422392. Eligible fraction zero remains valid screening evidence.
- Exact first-version simulation protocol snapshots freeze the burden join. Refit uses every observed eligible first-version persona decision with a known exact snapshot, including T14's historical fixture protocols and both prompt versions. Unsampled NULL enrollment and ineligible rows are excluded. Missing snapshots fail explicitly rather than being reconstructed from current trial data.
