- Exact consecutive events only. Earliest/current comparison is provenance, never silently attributed to a dated adjacent amendment. No confirmed original means no shortfall label.
- Shortfall uses an original ESTIMATED count and current ACTUAL count, preserving valid zero. Amendment negatives require complete history; incomplete evidence is unknown.
